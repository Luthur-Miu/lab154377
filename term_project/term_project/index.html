ที่มาและความสำคัญ
  • จากเหตุการณ์น้ำท่วมและภัยแล้งที่เกิดขึ้นซ้ำแล้วซ้ำเล่าในอดีต ทำให้เกิดข้อสงสัยว่า ปัจจุบันเขื่อนทั่วประเทศยังสามารถรองรับน้ำฝนที่อาจตกหนักต่อเนื่องได้อีกมากน้อยเพียงใด และในช่วงฤดูแล้งที่ขาดแคลนน้ำอย่างรุนแรง ปริมาณน้ำที่มีอยู่จะเพียงพอต่อความต้องการใช้น้ำหรือไม่
วิธีการดำเนินการพัฒนา
  • 1 เลือกหัวข้อและกำหนดขอบเขตของการนำเสนอข้อมูลขึ้นหน้าเว็บ
  • 2 รวบรวมข้อมูลที่ต้องการใช้ ทั้ง API ของเขื่อน และพิกัดภูมิศาสตร์
  • 3 ออกแบบหน้าเว็บให้ใช้งานง่าย โดยไม่นำแผนที่ กราฟ และรายละเอียดมาแสดงปนกัน
  • 4 ใช้ Visual Studio Code ในการพัฒนาเว็บไซต์
